04 / Read the assumptions

A small model, not a trading system

Past, then position.

For period t, use P[t−1] / P[t−1−L] − 1. The first L periods stay in cash. Go long only when the signal is strictly greater than the threshold; equality means cash. Trade at P[t−1], then earn the period's return to P[t].

This assumes immediate execution at the observed boundary price. No market-open gap, processing delay or executable quote is modeled.

Fees come from capital.

Start with 1 unit and no shares. At entry, shares = cash / (price × (1 + c)), where c = bps / 10,000. At exit, cash = shares × price × (1 − c). Shares stay fixed between trades; cash earns zero. Terminal sales are charged.

Net capital = 1 + gross mark-to-market P&L − cumulative fees. Return drag also includes foregone compounding, so it is not the same as fees paid.

Invented, not inferred.

Every path is generated locally from a seeded xorshift32 sequence. Trend / reversal adds ±0.2% drift in three 120-period blocks with ±0.8% uniform noise. Alternating adds ±0.9% with ±0.3% noise. Flat returns zero.

No dates, market data, shorting, leverage, taxes, spread, impact, funding, optimization or claims of predictive skill. Periods are abstract; no annualized statistics. Educational illustration, not investment advice.

Background: Time series momentum · Self-financing costs · How fees affect returns. This is a long/cash teaching simplification, not a reproduction of the paper's diversified, volatility-scaled futures strategy.
